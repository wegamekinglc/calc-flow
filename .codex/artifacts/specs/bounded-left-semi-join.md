# Bounded left semi join

A bounded left semi join emits a left row once when any right row has equal non-null keys and a representable event time within the inclusive interval from `left_time - before` to `left_time + after`. Distinct left input identities remain distinct even when every payload value compares equal. Return the complete declared left schema, including names, order and nullability. A native Arrow schema also retains its metadata. Python/project field declarations use their existing normalization. Pair joins use `left_prefix` and `right_prefix` to distinguish columns from the two sides. A left-only result uses its input names.

## Declaration and execution

- Add `left_semi` to the native bounded Join type and project-v3 contract. Provide a public Rust declaration, typed operator execution, the Python expression `cf.table.stream_join(..., join_type="left_semi")` and the advanced Python project builder. Existing inner declarations serialize with their existing identities and fingerprints. The SQL table function named `CF_INNER_JOIN` keeps its inner contract.
- Emit a newly witnessed left row when a data handler proves its first match. For a left ingress, process admitted left rows in source order. For a right ingress, process right rows in source order and new eligible left witnesses in `(event_time, row_id)` order. Multiple right witnesses in one Batch or later Batches produce one output for each left identity. Finite execution runs the same kernel with fresh state and returns an empty left-schema table when there are no witnesses.
- Preserve each ingress admission policy. A null event time cannot witness a match. A time conversion error precedes null-key classification. A null in any key prevents a match. Rows strictly earlier than their own input watermark are late. Equality with that watermark and with either interval endpoint is eligible. A right watermark strictly greater than `left_time + after`, or right EOF, closes that left row for future witnesses. Idle alone does not close a row. Retained right rows can still witness a later left ingress while the left side remains open.
- The match limit counts newly emitted left rows across the complete incoming Batch and all RecordBatches. Output row and byte limits count the actual left-only envelopes. Before publishing state, preflight every output and check cancellation. Preserve the source position, witness bits and next output sequence on failure. A retry after a returned error follows the same order. If a collector accepted a prefix before a later error, delivery follows the sink contract. A dropped processing future requires job recovery.
