## 发现与修订

1. `docs/symbolic-design.md` 仍声称 linear decay 扫描每个窗口。
   对照 `kernel/decay.rs`、`kernel.rs` 及 `tests/decay_tests.rs`，改为当前
   Float64 Rows 的认证增量摘要、重建与 reference fallback，并说明事务性队列复制的成本。
   不把已测加速扩展成所有类型、帧或整个作业的线性复杂度保证。
2. `docs/sql-datafusion-performance.md` 的配置表只把 `max_partitions` 归于
   `auto`，且把行数上限称为“两种模式”。对照 `DataFusionConfig::default`、
   `parallelism_decision` 和 `batch_sql_parallelism_decision`，明确三种自动策略
   的 requested cap，以及包括 `fixed` 在内的行数 work cap，并对齐表格。
3. 修复四处相对链接：SUM sharding 规格的目录层级、P2 规格中把 `:行号`
   拼进文件名的两处链接，以及 core-count sweep 指向仓库未收录表格的链接。
   后者改链实际保留的 sweep JSON，明确缺失的七引擎原表不能由该 JSON 复核；
   不重构历史数据或编造替代测量。
4. 对齐 `benchmarks/risingwave/README.md` 的五张表，仅调整空格和分隔行，
   维持固定版本、所有测量数字与结论。
5. 补齐 Multica `cf-performancer.instructions` 缺失的 canonical 功能测量规则，
   见下一节。其余 agent 文本保持原值。

这些修订没有改变产品行为、公共接口、项目或检查点格式，不增加 CHANGELOG。
