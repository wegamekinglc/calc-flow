# 复测单次 Rust ASOF 产出水位

左右各 10 万行、64 个键，先接纳两侧数据，再推进一次可产出全部匹配的水位。发布版为 7012b5b4，候选为 PR 750 的 9aed8b4b。原生观测与 Python 安装包使用独立计时。输出检查涵盖总行数、非递减顺序、左右序列号相等以及每行的右值关系。

历史上 72072c1d 相对发布版的内部处理器平均差距为 +5.343 ms，Arrow 输出为 +4.772 ms。本次使用同一原生负载；每组分两轮各十对正式样本，并分别预热。每个成功的插桩样本验证外层水位时钟包住内部处理器时钟，各内部阶段、Arrow 各子阶段分别求和闭合。[历史阶段测量](https://github.com/wegamekinglc/calc-flow/blob/d0fee918f7277557bd068d3da285dfaa44d2a152/benchmarks/evidence/20261125-asof-watermark-phases/native-phase-summary.md)

普通产品 Rust 回调 p50 为 8.467 → 6.127 ms，p95 为 9.028 → 6.528 ms，两轮判定为 improved。

同一对中的候选减发布版，然后对 20 个差值求算术平均。单位为毫秒，负数代表候选更快。

- 外层水位回调 -2.2360 ms
- 内部处理器 -2.2315 ms
- 匹配与就绪 -1.3819 ms
- Arrow 输出合计 -0.5300 ms
- 其中预算与整段判定 +0.1563 ms
- 其中列定位与取值 -0.6794 ms
- 其中 Arrow 组装 -0.0075 ms
- 其中其余输出管理 +0.0005 ms
- 左侧提交 +0.2414 ms
- 右侧状态淘汰 -0.7794 ms
- 交付等待 -0.0011 ms
- 未归属处理器时间 +0.2194 ms
- 内部处理器以外 -0.0045 ms

按各自普通产品 p50 作参照，插桩外层回调 p50 分别变化 -4.41% 和 -3.26%。普通与插桩组顺序运行，变化同时可能包含时间漂移。这是候选全部已纳入改动相对 11.14 的差值，不能单独归给输出计划复用。
