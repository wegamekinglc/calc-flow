Rust 原生表预先接纳左右各 10 万行，仅对右侧推进水位，计时到处理器返回。随后推进左侧，独立以每个应输出的物理行号生成预期值，核对左右两侧全部十个字段、非空性、顺序和总行数。Python 使用独立安装的 wheel，从各侧 100 万行的输入就绪计时到完整 Arrow 表交付，独立核对整表投影值、物理行序、EOF 和终态。Python 的默认调度不保证右侧先到。

每个完整组包含两轮、每轮十对正式计时以及每轮每侧一次预热。stopped 表示触发资源或时间等限制，已收取的样本仅供校验，不推算分位数或速度。具体状态、原因和样本数见 JSON。
