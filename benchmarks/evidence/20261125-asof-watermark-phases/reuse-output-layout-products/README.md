Rust 原生表预先接纳左右各 10 万行，推进可以产生全部匹配的水位，计时到处理器返回，再校验总行数、非递减顺序，并逐行核对左右序列相等及右值等于左序列的三倍。这个 Rust 校验不能识别所有重复替代或遗漏。Python 使用独立安装的 wheel，从各侧 100 万行的输入就绪计时到完整 Arrow 表交付，独立核对整表投影值、物理行序、EOF 和终态。两个入口的计时均包含匹配和其他输出工作，无法从总时长直接计量单次定位检查。

每个完整组包含两轮、每轮十对正式计时以及每轮每侧一次预热。stopped 表示触发资源或时间等限制，已收取的样本仅供校验，不推算分位数或速度。具体状态、原因和样本数见 JSON。
