# 完整批次 ASOF 接纳预算的千万行对照

测试的产品为 `5540d317884b59c53a8a9f80ac7129b78314c694`。两个对照分别是 11.14 的 `7012b5b4` 和前序匹配优化 `e3104f44`，直接使用 run 45691470579 已封存的正常优化产品。本次新增两个候选构建。所有组均检查每侧一千万输入行、64 个键、全部输出顺序和值及 EOF 后空状态。

Python 两组在同一台 AMD EPYC 9V74 VM 上依次执行。四个 Tokio worker 固定在两个物理核各一条逻辑 CPU。每组两轮，每轮预热各产品一次，然后交替测量十对。两组共 88 次逐行校验通过。
