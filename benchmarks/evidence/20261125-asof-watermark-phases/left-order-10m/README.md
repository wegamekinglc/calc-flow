每个完整组两轮，每轮各产品预热一次，再交替采集十对。每轮配对中位数与区间独立计算。正式回退线要求两轮的置信下界均超过 +5%。下表每个区间的覆盖率均为 97.85%。

每组使用独立的 GitHub 托管 VM，只比较同一台 VM 上交替运行的两款产品。三组完整数据来自 Intel Xeon 6975P-C，四个 Tokio worker 使用两个不同物理核的逻辑 CPU 0 和 1。Rust 直接父组使用 AMD EPYC 7763，逻辑 CPU 为 0 和 2。在两个预热后，预留的 SMT 同胞 CPU 3 利用率达到 100%，超过 50% 上限。该区间外部主机占用 25.44%，可用内存 14.63 GB，缺页和交换页计数均为零。此组取得零对正式样本。工作流按登记协议报失败，保留全部已完成的对照和资源记录。

工作负载为双侧各一千万行、64 个键、零容差、四个 worker。每次完成的观测均核验输出逐行顺序和值、双侧接纳与匹配数量、右侧淘汰和 EOF 后空状态。候选为 f67422bac9c0e23a8d22e717422c7b5bb329f723。已有普通产品按清单和哈希复用，11.14 为 7012b5b409553df04e29e6d7f9a11abf919cbf93，直接父为 5540d317884b59c53a8a9f80ac7129b78314c694。Rust 通过原生二进制执行，Python 通过独立环境安装 wheel 执行。
