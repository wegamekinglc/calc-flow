# 原生 ASOF 左侧提交分解

每侧 10 万行、64 个键。直接产出水位，单核单工作线程，发布版 7012b5b4 对候选 9aed8b4b。左侧时钟由互斥子阶段构成。前缀核验计候选提交时的 starts_with；预备工作计发布版的 prepare_prefix_checkpoint；状态变动计候选在核验成功后执行的状态清理，发布版计 commit_prepared_left_prefix。发布版的准备步骤包含可能的异步让出。发布版的剩余项包含提交尾部的 retirement.wait 和输出状态更新，候选在发送前完成相应状态计算，计入处理器剩余项。两版的子阶段均按各自实现边界计时。
