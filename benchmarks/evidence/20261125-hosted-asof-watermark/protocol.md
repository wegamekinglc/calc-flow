Compare 2026.11.14 (7012b5b409553df04e29e6d7f9a11abf919cbf93) with de20f8216c8dcb1bfce3e3811c3884a3080157df. The local four-worker cohorts stopped under host paging. Keep those cohorts independently reported. This study uses one native Tokio thread on a fresh GitHub-hosted Ubuntu VM, both products compiled on that VM with identical bench settings. A separate complete hosted suite on the same main measures installed Python at one and four workers (run 45623973262). Its scheduled native comparison uses a different baseline.

Use the established native ten-million-row managed job. Deliver ten one-million-row batches on each side, 64 string keys, zero tolerance, fixed arrival and watermarks. Validate every key, sequence and value in physical output order and validate both input inventories and post-EOF state on every accepted process. The ordinary clock times ready enqueue through final Batch formation. EOF is submitted after timing. The instrumented comparator adds only the archived exclusive watermark stopwatches to each original product. Trace every callback, including subsequent EOF work, with complete counter continuity and exclusive nanosecond closure of matching, Arrow, left commit, right expiry, emission and residual. Split Arrow into charge, column gathering, assembly/edge checks and bookkeeping. Report cumulative callback deltas separately from the outer clock.

Two independent cohorts: ordinary release/main and traced release/main. For each, use two rounds of ten alternating adjacent AB/BA pairs with four excluded warmups, 240 seconds per cohort including registration checks, process launch, preflight, full correctness checks and cleanup. Allow 60 seconds for replay, 540 seconds total; allow 120 minutes separately for cold optimized builds, dependencies and packaging. Pin both cohorts to the same measured physical CPU whenever the first preflight selected one. Report p50, p95, paired intervals and parent-clock means, including instrumentation overhead only with fully comparable ordinary controls. Preserve host memory/CPU/SMT/paging gates and stop reasons.
