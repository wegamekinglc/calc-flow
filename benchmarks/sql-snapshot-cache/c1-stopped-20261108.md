## Actual stop

The first sparse baseline process (PID 62419, creation time 1794128716.88)
completed with OS exit 0 and was reaped. It emitted a full JSON report, but
`NUMEXPR_NUM_THREADS`, `VECLIB_MAXIMUM_THREADS` and `RAYON_NUM_THREADS` were
absent; the frozen protocol requires each to equal `"1"`. The controller used
the maintained generic child environment without adding the full C1 protocol
map. The strict selected-report validator correctly rejected the report.
This is a launcher/protocol mismatch, unrelated to application authentication.

The collector exited 1, was reaped, and left no owned processes. Its outer
receipt records 1.228403 seconds from the original phase clock; error cleanup
was observed at 1.230228 seconds. Exact terminal duration including tail writes
was not separately recorded. Exactly one
native baseline process ran; zero accepted observations, zero complete pairs,
zero candidate processes and zero dense-case processes were collected. There
is no results/statistics file. The expected 80-process acquisition did not
complete. Raw baseline times cannot establish a candidate comparison.

## Repair and disposition

The exact failed-phase controller, tests, config and then-current review were
preserved before editing. A focused regression exercised actual controller
initialization and reproduced the three missing values. The TARGET-only repair
merges the frozen C1 thread map into a fresh owned child environment. All 22
controller tests passed afterward; Ruff check/format passed. Frozen product
sources, native binaries, validator strictness, case selection, row counts,
sample counts and statistical thresholds were unchanged.

No native retry, additional probe, retuned workload or pooled sample was run.
The protocol requires stopping on environment/identity failure, and the user
requires real performance improvement before merge. Consequently this attempt
has no mergeable performance evidence. P2/P3 remain the independently measured
and merged improvements; D1/D2 continue separately.

CI at disposition is not claimed green: coverage baseline verification passed
on its targeted rerun, while the Python tests passed but the Coveralls reporter
download failed checksum validation; Rust coverage was still running at the
last observation. No validation was weakened. Required CI and final merge
review were never satisfied for C1.
